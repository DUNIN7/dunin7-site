# dunin7.com

DUNIN7 operating-account domain landing page. Static HTML served via Cloudflare Pages.

`dunin7.com` is the operating-account domain (email, `foraychallenge.dunin7.com` subdomain). This page is functionally a directory pointer to `doneinseven.com`, the public product-family root.

## Stack

Plain HTML with inline CSS. No build tooling, no framework, no JavaScript.

## Deployment

Cloudflare Pages auto-deploys on push to `main`. Production domain: `dunin7.com`.

## Editing

Edit `index.html` directly. Commit and push to `main` — Cloudflare Pages picks up the change and re-deploys within ~1 minute.
